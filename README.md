# Audio Toolkit Short

Audio Toolkit Short is a tool for separating tracks, transcribing notes, and identifying chords in audio recordings.

- **Track separation:** Split a recording into individual tracks such as vocals, drums, and bass. Listen to each track on its own, download it, or combine tracks into a new mix.
- **Audio to MIDI:** Convert notes in a recording into editable MIDI. Preview the detected notes and listen to the transcription before downloading it.
- **Chord analysis:** Identify chords throughout a recording, see when they change on a timeline, and export the results as a JSON report.
