# Audio Toolkit Short

This is the independent three-tool edition at D:/tools/audio-toolkit-short, created at the user request.
Only expose stems, midi and chords. Preserve local CPU processing, EfficientAT and five-fold chord models, and private anonymous LAN sessions with protected administrator APIs.
Do not modify the full project D:/tools/audio-toolkit-main-java-vue or original Python project D:/tools/audio-toolkit-main while developing here.
Vue lives in src/, Java in server/src, private Python algorithms in worker/. Preserve Host/Origin checks, CSRF and task/file ownership. No paid calls during tests.
Use port 8081 for local Java and 5174 for Vite to avoid full-edition conflicts. Docker short edition has its own Compose name and volume; never apply short patches to a full-edition deployment.
Do not copy user accounts, jobs, credentials, logs or .git from the full edition. runtime/ models and binaries are private ignored runtime assets; never commit or include them in source bundles.
Build with pnpm build and scripts/Build-Server.ps1 (JDK17+ Maven fat JAR). Validate with tests/short_integration.py, Python model/API tests and local browser preview. No Sites publication.
